# v0.2.2 今日计划覆盖更新

2026 年 11 月 17 日。沿用 Java 和 SQLite，数据库表结构及版本不变。

## 使用行为

用户修改今日状态并点击“保存今日状态并生成计划”后，更新同一天已有的自动计划，沿用计划 ID，并将动作、组次、推荐说明和状态快照替换为本次生成结果。当天状态记录同样更新保存。

再次生成时，旧版同一天重复生成的自动计划与状态记录会合并为各一份。判断依据为日期和自动计划的状态快照，不依赖计划名称；自动计划被重命名后仍参与更新，自定义名称保留。

手动新建的计划和其他日期的计划继续保留。活动中的训练与历史使用独立快照，因此已经完成的组和当前训练内容不会因更新模板而改变。

如果最新状态不生成训练计划，例如选择明显酸痛或疼痛，则保存最新状态并撤下当天旧自动计划，避免继续展示过期安排。已经开始的训练快照和历史记录保留。

## 保存方式

`HomeScreen.submitCheckin` 先生成候选计划，再由 `Store.saveDailyPlan` 在一个 SQLite 事务内更新状态和计划、合并同一天的旧重复记录。复用现有记录的 ID，忽略外部传入的其他记录 ID，避免覆盖其他日期或手动计划。

任一步保存失败时回滚整个事务，旧状态和旧计划保持原样，界面提示重试。缺少日期或计划快照日期不一致时拒绝保存。重新生成会以新推荐结果替换自动计划中的手动组次修改；正在执行的训练仍保留开始时的副本。
