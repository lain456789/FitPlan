# v0.3.0 训练中调整

2026 年 11 月 17 日。实现第二个创新点，继续使用 Java 原生 Android 和 SQLite。数据库表结构与版本保持不变，新增字段保存在现有 JSON 文档中。

## 按剩余时间缩短

开始训练后，页面顶部显示已完成组、待完成组和粗略剩余用时。点击“按剩余时间缩短”，填写 0–180 的整数分钟数，查看动作与组数变化，再确认保存。

估计沿用每个剩余组约三分钟的产品规则，计入当前尚未结束的休息，不重新加入训练前热身时间。按现有动作顺序先保留各项的一组，再分配额外轮次。只减少未完成且未取消的组，不增加内容；足够容纳当前安排时不生成无效调整。用时是粗估，不承诺实际训练一定在该时间内结束。

被取消的组保留原位置，并显示取消原因。已完成组的原动作、组号、重量、次数和完成状态逐条保持不变。剩余时间为零时可取消全部待完成内容并结束当前休息，随后保存已完成记录；没有完成任何组时仍可选择放弃本次训练。

## 器械不可用时替换

动作卡片中有待完成组时，点击“器械不可用，替换未完成组”。选择不可用器械，查看同类候选及其器械要求，选择适合的动作后，重新输入重量和次数。重量输入初始为空；自重动作可明确填写零。预览确认后，原动作的未完成组标记为已替换，新动作以独立行接续相同数量的组。

原动作已完成的组保留在原行，不能因替换而改成新动作名或新重量。所有已标记不可用的器械在本次训练后续候选筛选中继续生效；候选的辅助器械也参与排除，例如训练凳不可用时不会推荐仍需要训练凳的哑铃卧推。

候选使用人工整理的动作类别和器械标签，不仅按身体部位匹配，也不表示动作难度、训练效果或负重等同。新增 14 个补充动作，合计 30 个内置动作；原有内置 ID 和用户自定义动作保留。额外候选不改变原每日自动计划默认选择范围。自定义动作暂未配置替代关系，条件下没有合适候选时明确提示，可返回缩短剩余安排。

器械事实与动作名称参考 [ACE Exercise Library](https://www.acefitness.org/resources/everyone/exercise-library/)、[ACE Dumbbell Exercise Library](https://www.acefitness.org/resources/everyone/exercise-library/equipment/dumbbells/)、[Utah State University Resistance Training Exercises](https://extension.usu.edu/fscreate/files/2020-22-staff/Resistance_Training.pdf)。动作类别和候选组合是本项目的产品规则，不是经验证的个体训练处方。未复制动作照片、视频或完整指导文字。

## 保存和复盘

预览使用训练数据的独立副本，取消预览不会改变数据库。确认时在 SQLite 事务中再次检查当前训练是否与预览依据一致，并验证所有已完成组未变；预览过期、重复确认、写入失败都会阻止覆盖。已完成训练不能被旧预览重新恢复为进行中。

首次调整保留原始行快照，每次调整保存原因、时间、动作变化和版本序号。取消的组不计入统计，替代动作使用自己的动作 ID，完成后正常记录及计入周报。模板计划和其他历史记录不受当前训练调整影响。训练页和历史详情均可查看本次调整记录。

## 验证结果

- `assembleDebug`、`testDebugUnitTest`、`lintDebug`、`assembleDebugAndroidTest` 成功。
- 37 项 Java 单元测试全部通过，包含新增 9 项时间分配及器械筛选测试。
- Android 15 / API 35 的独立 FitPlanVerification 模拟器执行 32 项设备测试，全部通过且无跳过；包含新增 12 项训练调整测试。
- 另单独重跑两个界面流程，检查弹窗动画结束后的中英文页面和预览截图，两项均通过。
- 验证交错顺序的完成组保留原组号，连续替换和缩短、零剩余时间、取消预览、过期预览、重复应用、篡改完成记录的保护、保存失败回滚、SQLite 重开、模板隔离和实际完成量统计。
- 界面流程覆盖未填写替代重量时阻止提交，设置新重量后预览和确认，继续记录替代动作，结束保存并查看历史。
- Lint 无错误，25 项非阻断提示主要涉及资源复数形式、绘制和既有工程建议。本次未额外执行 API 24 或物理手机测试。
- 日常使用的 FitPlanP0 模拟器覆盖更新至 v0.3.0，升级前后全部 18 条原有 SQLite 记录的 ID、类别、内容与更新时间一致，仅新增 14 条补充动作库记录。测试数据位于独立模拟器，未导入日常设备。
