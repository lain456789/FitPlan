## 测试关注点

- 周一边界、跨年、夏令时和当前周同期比较。
- 仅计入完成组、自重动作、上期为零、历史修改/删除重算。
- 同名不同动作 ID 的隔离、每次训练最大重量、缺失日期不补零。
- 计划和训练快照独立、完成后迁移到历史、本地数据库重新打开后记录保留。
- 中英切换、内置名称与自定义名称、每日表单草稿、所选周及休息时间保留。

## 限制

设备测试通过公开 View 回调验证流程，辅以实际屏幕截图检查；不是所有真实触摸操作、品牌设备或字体尺寸的穷尽测试。Lint 仍有非阻断建议。周报计算已移到后台线程，其他部分数据操作仍在 UI 线程；大规模历史数据性能需要进一步验证。
