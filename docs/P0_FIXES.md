# v0.2.1 推荐规则修复记录

2026 年 11 月 17 日。保留 Java 原生 Android、SQLite 和现有 JSON 文档存储，数据库版本及原有记录不变。项目原有 AGP 9.5.1、Gradle 9.6.0 和 compile/target SDK 37 设置保持一致。

## 状态减量不再增加总组数

先按正常状态、可用时间和候选动作确定基准动作数量，再对固定的动作列表减少组数。不会用减组释放的时间补入新动作。每动作至少一组；已经只有一组时不再减少，但总组数不会增加。

回归场景：30 分钟、胸和背、常规训练量，正常状态为两个动作各三组，共六组；触发状态减量后为相同两个动作各两组，共四组。估计时间仍按每组三分钟及热身五分钟计算。

计划详情显示当前总组数、估计时间、生成时的正常状态基准、时间限制和当前未覆盖的所选部位。手动调整后，当前总组数与估计时间重新计算；超过填写的可用时间时提示检查。

## 重量参考使用可比完整记录

按动作 ID 筛选记录，要求历史目标次数一致、计划组数足够、实际记录完整、每组均完成并达到目标次数，重量为有效非负数。参考值采用可比记录中各组均已支持的最低重量，不把单个较重组复制到全部组。最近训练不满足条件时继续查找较早的可比记录，并展示实际采用记录的日期、组数和次数。

例如 40、45、50 kg 各完成一组十次，下一次参考值为 40 kg；80 kg 仅完成一次不能成为十次训练的参考。没有可比完整记录时，重量保持待确认，须打开调整界面保存确认后才能开始；自重可明确确认为零。

旧版自动生成的计划可能使用最高重量规则，因此升级后也需要确认。不会自动重写旧计划或历史。当前尚无器械变体及主观难度字段，这些维度留待后续功能实现。

## 手动修改与说明保持一致

保存修改时记录用户确认值和时间，保留首次修改前的快照，并移除当前值上已失效的自动推荐原因。再次修改不会覆盖首次快照。新版自动生成的计划显示“生成时的值”；旧版计划可能早已被修改，无法准确恢复生成值，因此显示“本次首次确认前的值”。仅打开对话框或输入无效值不修改快照。

修改模板不改变已经开始的训练副本，历史和周报的原有独立保存方式继续保留。
