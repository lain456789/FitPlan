# v0.4.1：风格与术语整理

本次整理覆盖 22 个业务 Java 文件、6 个单元测试文件和 9 个设备测试文件。Java、SQLite、页面路由、训练规则和统计计算方式继续沿用 v0.4.0。

## 改动

- 固定使用 google-java-format 2.0.0 的 AOSP 风格，统一 4 空格缩进、换行、空格、导入顺序和文件末尾换行。长字符串保留原内容。
- 展开通配符导入，删除未使用的导入。公共页面中的 Activity 引用命名为 `activity`，关键输入变量区分实际值与目标值。
- 把连续 3 次、最多 7 条记录、进阶目标上限 20 次等原有数值改为具名常量；比较条件、边界和判断顺序保持一致。
- 统一“已训练组 / Performed sets”“达标组 / Sets meeting the target”和“待训练组 / Pending sets”，明确少于目标次数的已训练组仍按实际记录参与统计。
- 整理主布局 XML 的属性排版；元素结构及属性值保持一致。
- 增加 `.editorconfig` 和 [协作规范](../CONTRIBUTING.md)。新增 `formatJava`、`checkJavaFormat`，根项目 `check` 同时执行格式与 App 常规检查。
- 调试版本更新为 0.4.1，APK 为 `downloads/FitPlan-v0.4.1-debug.apk`，历史安装包保留，校验值见 `downloads/SHA256SUMS`。

内部的 `done` 数据字段、`completed_sets` 资源键和偏好值保留，以兼容已有记录。SQLite 表结构不变；格式工具是独立开发依赖，不加入 App 运行时。
